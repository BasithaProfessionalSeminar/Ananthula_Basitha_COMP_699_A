## Multi-Objective Decision Support System

### Developed by Bhasitha Ananthula

---

## About This Project

This project is a Multi-Objective Decision Support System developed to help organizations make better business planning decisions. In many real situations, companies need to make decisions where multiple goals are involved, like reducing cost, improving efficiency, and managing risk at the same time. Handling all these together using normal methods like Excel or manual thinking becomes very difficult and confusing. So in this system, Bhasitha Ananthula worked on building a structured solution where all these decisions can be handled in a clear and organized way. The system allows users to create planning scenarios, define objectives, set priorities, and evaluate different options in a proper method so that the final decision becomes easy and well justified 

---

## Why This System Is Needed

In normal business environments, decision making is not simple because many factors are involved and they may conflict with each other. For example, if we reduce cost, sometimes efficiency may also reduce, or if we increase performance, risk may also increase. Many organizations still use spreadsheets or manual calculations, but this creates problems like taking more time, giving different results for the same problem, and not clearly explaining why a decision was selected. So this system was developed to solve these issues by giving a structured and repeatable way to evaluate decisions. It improves clarity, reduces confusion, and helps users understand the trade-offs between different choices in a simple manner 

---

## What The System Does

This system helps users to create a planning scenario where they can define their problem clearly. After that, they can add multiple objectives such as minimizing cost or maximizing output. Each objective can be given a weight to show its importance. Then users can define constraints like budget limits or resource availability. Once everything is set, users can create different decision alternatives and enter values for each objective. The system then evaluates all alternatives using a proper model and gives ranked results. This makes it easy to compare options and select the best one. The system also allows reviewing and approving decisions so that the process remains controlled and reliable 

---

## Main Features

The system supports creating and managing planning scenarios in a simple way so that users can organize their decision problems properly. It allows defining multiple objectives and assigning weights based on importance, which helps in reflecting real business priorities. Users can also define constraints to make sure that all decisions follow practical limits. The system provides evaluation of alternatives and gives ranked outputs so that users can clearly see which option is better. It also supports comparison of alternatives and helps in understanding trade-offs using visual representation. In addition to that, the system includes user roles like planner, reviewer, and administrator to manage access and maintain proper control over the process 

---

## How The System Works

The system works in a step-by-step process where first a planner creates a scenario and defines all objectives and constraints. After that, different alternatives are added with their values. Then the system calculates scores based on the defined weights and rules. Once the evaluation is done, the system generates a ranked list of alternatives. The planner can review these results and submit the scenario for approval. The reviewer can then check all details and either approve the decision or request changes. This complete process makes decision making more structured and easy to follow compared to manual methods

## Technologies Used

This system is developed using Python as the main programming language. Only free and open-source libraries are used in this project, as per the requirements. ## System Requirements

To run this project, a normal computer or laptop is enough. There is no need for any special hardware. The system requires Python to be installed along with required libraries. Since it is designed as a simple application, it can run smoothly on basic systems without high performance requirements. Users can interact with the system through a simple interface, and no advanced technical knowledge is required to use it 

---

## How To Run The Project

First, make sure Python is installed on your system. Then install the required libraries using pip. After that, download or copy the project files into your system. Open the terminal or command prompt and navigate to the project folder. Then run the file using the command python system.py. Once the application starts, you can log in and begin using the system features like creating scenarios, defining objectives, and evaluating alternatives.
